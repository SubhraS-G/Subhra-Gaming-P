# Animation Guide

The website should feel animated, but the animation must support the gamer identity.

## Hero Entrance

Duration:
~1.2–1.8 seconds

Sequence:
- Background
- SUBHRA wordmark
- Portrait
- UI
- Identity
- CTA

## Parallax

Keep movement subtle.

Recommended relationship:
- Background: 1x
- SUBHRA: 1.05x
- Portrait: 1.10x
- UI: 1.12x

## Hover

Cards:
- scale approximately 1.02–1.04
- reveal metadata
- subtle border/lighting change

Buttons:
- slight translation
- arrow movement

## Scroll

Use:
- fade-up
- small translation
- image reveal

Avoid:
- long scroll-jacking
- giant rotations
- excessive blur
- distracting particle effects

## Performance

Prefer:
- CSS transforms
- opacity
- requestAnimationFrame for pointer effects

Avoid unnecessary heavy WebGL for the initial portfolio.
